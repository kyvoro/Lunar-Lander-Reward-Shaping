# Project contributions

This is Luca's study and portfolio project. He defined the landing objective and reward preferences, set the full-pad success criterion, completed guided Python and reinforcement-learning exercises, and directed project decisions and review of results.

Codex supported the work as a tutor and coding assistant through explanations, debugging, code review, and verification. At Luca's explicit request, Codex also wrote or modified several scripts. The project is therefore Luca-led with coding assistance; this document does not claim that every line of code was independently authored by Luca.

The experiment methods, measured results, and limitations are documented in [the experiment log](experiments.md) and the [README](../README.md).
